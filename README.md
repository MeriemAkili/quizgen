# QuizGen

Application full-stack de generation de quiz par IA avec validation enseignante.

## Architecture
- Backend : Spring Boot (microservices)
- Frontend : Angular
- Base de donnees : PostgreSQL
- IA : Generation de quiz a partir de PDF

## Services
- discovery-service (Eureka)
- api-gateway
- auth-service
- course-service
- quiz-generation-service
- quiz-service
- attempt-service
